# Google Stitch 조작 안내

Stitch는 프롬프트로 화면을 만들어 주는 Google Labs의 디자인 도구다.
주소는 https://stitch.withgoogle.com 이고 구글 계정으로 로그인한다.

## 직접 생성 (Stitch MCP) — 기본 경로

Stitch는 MCP 서버를 제공한다. 도구 목록에 Stitch 도구가 보이면 아래 수동 조작
없이 직접 화면을 생성한다.

- 공식 원격 MCP 서버: stitch.googleapis.com (Google Cloud 프로젝트에서
  Stitch API 활성화 필요)
- 프록시형: stitch-mcp, stitch-mcp-auto 등 (npx로 실행, gcloud 인증 사용)

직접 생성 시 지켜야 할 것은 수동 조작과 동일하다: 한 프로젝트 안에서 화면을
이어서 추가하고, 수정은 해당 화면에만 짧은 지시로 보낸다.

도구가 없거나 인증·권한 오류(401/403, OAuth 미완료, API 미활성화), 사용자 거부,
사용량 초과가 생기면 "권한 막힘"이다. 이때는 프롬프트를 채팅에 출력하지 말고,
아래 수동 조작 순서를 요약해 문서 앞부분에 넣은 뒤 프롬프트 문서(md 파일)로
저장해 전달한다.

# 수동 조작 순서 (폴백 문서 앞부분에 요약해 넣을 내용)

## 프로젝트 만들기

1. 새 프로젝트를 만들 때 **Web 모드**를 선택한다. App 모드는 모바일 세로 비율로
   생성되므로 5:4 가로 슬라이드가 나오지 않는다.
2. 프로젝트 설정에 DESIGN.md 등록 기능이 보이면, 스킬이 만들어 준 DESIGN.md 전문을
   등록한다. 안 보이면 건너뛴다(각 프롬프트의 STYLE BLOCK이 같은 역할을 한다).

## 슬라이드 생성

3. 1번 슬라이드 프롬프트를 입력창에 붙여넣고 생성한다.
4. 같은 프로젝트 안에서 다음 프롬프트를 이어서 입력해 화면을 추가한다.
   새 프로젝트를 만들면 스타일 기억이 초기화되므로 반드시 한 프로젝트에서 진행한다.
5. 마음에 안 드는 슬라이드는 해당 화면을 선택하고 수정 지시를 짧게 덧붙인다.
   예: "Make the heading larger and move the cards down."

## 내보내기

6. 각 화면을 이미지(PNG)로 내보낸다. 화면 선택 → 내보내기/Export에서 이미지 저장.
   코드(HTML/CSS)나 Figma로도 내보낼 수 있지만, 이 스킬의 3단계는 이미지를 사용한다.
7. 파일명을 슬라이드 순서대로 01.png, 02.png ... 로 바꿔 두면 3단계 조립이 편하다.

## 참고: 무료 사용량

Stitch는 월 사용량 제한이 있다(모드별로 다름). 슬라이드 10장 내외 프로젝트에는
충분하지만, 재생성을 반복하면 소진되므로 프롬프트를 정확히 넣고 시작하는 편이 좋다.
