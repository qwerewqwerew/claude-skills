아래 값은 원본 파일에서 MCP로 직접 추출한 실측값이다. 임의로 바꾸지 않는다.

## 2. 타이포그래피

원본은 Poppins(제목 SemiBold/Bold, 본문 Regular) + Anteb Medium(표지 강조 행)이다.
한국어 대응은 다음으로 고정한다.

- 제목·강조: Noto Sans KR Bold (Poppins SemiBold/Bold 대응)
- 본문: Noto Sans KR Regular
- 숫자·영문이 섞이면 Poppins와 Noto Sans KR을 병기: font stack "Poppins, 'Noto Sans KR', sans-serif"

크기 감각(1280×1024 기준): 표지 제목 53~70px, 섹션 디바이더 대형 타이포 93~120px,
본문 슬라이드 제목 40~48px, 카드 제목 24px, 본문 16px(행간 1.5, 자간 약간 좁게).
제목은 자간을 살짝 좁혀(-2~-4%) 단단한 인상을 준다. 본문은 양쪽 정렬(justify)을 쓴다.

## 3. 장식 요소(템플릿의 시그니처)

- 모서리에 걸쳐 잘린 원(circle blob): 회색 또는 오렌지, 지름 100~235px, 화면 밖으로 반쯤 나감
- 배경의 부드러운 블러 글로우: 흰 배경 모서리에 옅은 오렌지/회색 그라데이션 번짐
- 점선 두들(dashed doodle): 오렌지 점선 곡선 + 종이비행기 같은 라인 일러스트
- 얇은 오렌지 세로 룰(2~3px): 제목과 설명 단락을 나누는 구분선
- 키워드 하이라이트: 문장 중 핵심 단어 뒤에 오렌지 사각 박스(텍스트는 흰색) 또는 오렌지 밑줄

## 4. 슬라이드 원형 7종

### cover — 다크 표지
배경 #212121. 왼쪽 정렬 2행 제목: 1행 흰색(부제), 2행 오렌지(회사/발표명).
오른쪽에 크게 확대되어 블러 처리된 오렌지 로고/도형 모티프. 좌상단에 옅은 오렌지 글로우.

### divider — 섹션 디바이더
배경 #FAFAFA + 모서리 블러 글로우. 화면 중앙에 초대형 볼드 타이포 1~2행
(오렌지 또는 #424242). 질문형 문구가 템플릿의 특징이다("무엇을 하는가?", "왜 우리인가?").

### card-grid — 카드 그리드(3~4열)
상단: 왼쪽 대형 제목(#424242, 2행) + 얇은 오렌지 세로 룰 + 오른쪽 오렌지 본문 단락.
하단: #F5F5F5 카드 3~4장. 카드 안은 오렌지 라인 아이콘(43~63px) → 볼드 제목 → 본문 순.
카드 사이 간격 약 39px, 카드 안쪽 여백 22px.

### split-panel — 좌우 분할 리스트
왼쪽: 대형 제목(핵심 단어만 오렌지) + 이탤릭 부제 + 점선 두들 일러스트.
오른쪽: 라운드 코너(약 16px) 오렌지 그라데이션 패널. 패널 안에 항목 3개를 세로로 쌓고,
각 항목은 흰색 볼드 제목 + 흰색 라인 아이콘 + 흰색 본문.

### photo-highlight — 사진 강조
흑백 인물/현장 사진을 오른쪽에 배치(원형으로 크롭하거나 원 위에 얹음).
왼쪽에 대형 헤드라인: 핵심 단어에 오렌지 하이라이트 박스와 오렌지 밑줄.
왼쪽 가장자리에 얇은 오렌지 세로 룰, 하단에 이탤릭 캡션 한 줄.

### logo-grid — 로고/항목 그리드
상단 중앙 제목 1행. 아래에 로고나 항목을 3×3 내외 그리드로 배치, 마지막에
"그 외 다수..." 류의 작은 문구. 모서리 원형 블롭 장식.

### closing — 마무리
배경 전체 #F48120. 좌측에 흰색 초대형 볼드 "감사합니다", 아래에 흰색 본문
1~2행(질문 유도 문구). 장식 없이 단순하게.

## 5. 구성 흐름(원본 템플릿의 순서)

cover → divider(질문) → 본문(card-grid/split-panel/photo-highlight) → divider →
본문 → logo-grid → closing 의 리듬을 따른다. divider를 본문 2~3장마다 하나씩 넣어
호흡을 만든다.
