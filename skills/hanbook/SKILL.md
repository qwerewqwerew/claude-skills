# Hanbook: PDF 한국어 번역

원본의 내용을 한국어로 번역한 별도 PDF를 만든다. 내용을 요약하거나 추가하지 않으며, 사용자가 달리 지정하지 않으면 원본 파일은 수정하지 않는다.

## 배치 방식 선택

- **원형 유지:** “원본과 같은 형식”, “페이지 수 유지”, “좌표 유지” 요청에 적용한다. 페이지 수·크기, 이미지·표·배경의 위치와 크기, 색상과 시각적 위계를 보존한다. 번역 페이지를 추가하거나 단순 텍스트 문서로 다시 조판하지 않는다.
- **한국어 배치 조정:** “읽기 편하게”, “재배치”, “페이지 변경 허용” 요청에 적용한다. 한국어 길이에 맞게 텍스트 영역, 행간, 표 셀, 이미지 위치와 페이지 나눔을 조정한다. 내용, 읽기 순서, 제목 위계, 이미지와 설명의 관계를 보존한다.
- 요청에서 방식이 정해지지 않거나 두 요구가 충돌하면 작업 전에 두 방식 중 하나를 짧게 질문한다. 임의로 방식을 바꾸지 않는다.

## 작업 범위

문서를 지정한 번역·테스트 요청은 별도 범위 지정이 없으면 전체 문서를 대상으로 한다. 임의로 대표 페이지 테스트만 수행하고 작업을 끝내지 않는다. 일부 페이지의 사전 검사는 전체 작업의 중간 단계로 처리하며, 중단 시 완료 범위와 남은 범위를 명확히 기록한다.

## 시작 전에

1. 작업에 쓸 도구(PDF 읽기·편집용 `pymupdf`, 페이지 렌더링, OCR, 한글 글꼴)가 설치되어 있는지 먼저 확인한다. 없는 도구는 임의로 설치하지 말고 사용자에게 알린 뒤 진행한다.
2. 입력 파일, 출력 파일명, 번역 범위, 보호할 원문을 확인한다. 명확하면 추가 질문 없이 진행한다.
3. 선택 가능한 글자, 스캔 이미지, 윤곽선 글자가 섞여 있는지 페이지별로 판별한다.
4. [scripts/analyze_pdf.py](./scripts/analyze_pdf.py)를 `python scripts/analyze_pdf.py <입력.pdf> --output <분석.json>`으로 실행해 페이지 크기, 텍스트 블록, 글꼴, 이미지 수를 기록한다. 스캔·윤곽선 글자는 이 분석만으로 추출되지 않으므로 OCR 또는 시각 확인을 보완한다.
5. [배치 보존과 품질 검사](./references/layout-preservation.md)를 선택한 방식에 맞게 적용한다.

## 원문 보호

사용자 지정 대상과 다음 항목을 번역 전에 보호 목록으로 만든다.

- `PROMPT`, `EXAMPLE PROMPT`, `NEGATIVE PROMPT` 아래의 실제 프롬프트 본문
- 코드, 명령어, 변수, 파일 경로, URL, 이메일 주소
- 프로그램 UI 명칭: 메뉴, 버튼, 탭, 대화상자, 설정 항목. 설명에 인용된 이름도 원서 표기를 유지한다.
- 로그, 오류·경고 메시지, 터미널 출력, 실행 결과 예시
- 모델명, 제품명, 회사명, 버전, 계정명
- 숫자, 단위, 날짜, 해상도, 화면비
- 이미지 내부 글자. 사용자에게 이미지 내부 번역 지시가 있을 때만 편집한다.

보호 문구를 충돌하지 않는 자리표시자로 바꿔 번역한 뒤 정확히 복원한다. 대소문자, 기호, 공백과 코드·로그의 줄바꿈을 보존한다. `Click Save`는 `Save를 클릭합니다`로 번역하며, 실제 오류 메시지 `File not found`는 그대로 둔다. 메시지를 설명하는 일반 문장은 번역한다.

원형 유지에서는 보호 문구를 원래 영역에 보존한다. 배치 조정에서는 긴 줄을 영역 확장이나 가로 배치로 수용한다. 보호 범위가 불명확하여 결과에 큰 영향을 줄 때만 질문한다.

## 번역과 배치

- 설명, 제목, 표 제목, 각주, 캡션을 자연스러운 한국어로 번역한다.
- 전문용어는 한국 초보자가 이해할 표현을 우선하며, 식별이 필요한 고유 영문은 괄호로 남길 수 있다. 같은 용어는 일관되게 번역한다.
- 원형 유지에서는 원문 좌표의 같은 영역에 삽입한다. 글자 크기를 먼저 유지하고, 넘치면 줄바꿈, 자간·행간, 글자 크기 순으로 최소 조정한다. 읽기 어려울 만큼 축소하거나 의미를 생략하지 않는다. 영역에 수용할 수 없으면 해당 부분과 대안을 제시하고 방향을 묻는다.
- 배치 조정에서는 자연스러운 줄바꿈과 행간을 정하고 필요하면 텍스트 영역·표·이미지와 페이지 나눔을 바꾼다. 영역에 맞추려고 글자를 과도하게 줄이지 않는다.
- 원문과 굵기·폭·인상이 가까운 한국어 설치 글꼴을 선택하고 PDF에 포함한다. 필요한 글꼴이 없으면 대체 글꼴을 알리거나 설치 가능 여부를 확인한다.

## 문서 유형별 처리

### 선택 가능한 글자가 있는 PDF

텍스트의 좌표, 회전, 정렬, 색, 크기와 굵기를 추출한다. 기존 글자만 제거하고 번역문을 삽입한다. 원형 유지에서는 이미지, 선, 배경, 링크와 책갈피를 보존한다. 배치 조정에서는 보호 문구와 번역문을 재배치하고 링크·책갈피·목차·페이지 참조를 새 위치에 맞게 갱신한다.

### 스캔 PDF

OCR로 원문과 좌표를 얻고 읽기 순서를 확인한다. 명령어·UI·로그의 인식 오류는 원본 이미지와 대조해 수정한다. 원형 유지에서는 원문 글자 영역의 배경을 복원한 뒤 번역문을 넣는다. 배치 조정에서는 본문과 도판을 구분해 재배치하고 프로그램 화면 캡처는 그대로 보존한다. 복잡한 배경, 곡선 글자, 이미지 내부 글자를 수정한 부분은 확대 검사한다.

### 편집이 어려운 PDF

윤곽선 글자나 배경에 합쳐진 글자는 OCR·이미지 추출과 배경 복원 가능성을 검토한다. 선택한 방식으로 보호 문구·도판·배경을 정확히 보존하기 어렵다면 영향받는 부분과 가능한 대안을 알리고 방향을 묻는다. 원형 유지 요청을 임의의 추가 번역 페이지로 대체하지 않는다.

## 필수 검증

1. 출력 PDF를 다시 열고 원문 내용 블록과 결과를 대응시켜 누락·중복·읽기 순서를 검사한다.
2. 원형 유지에서는 페이지 수와 각 페이지 크기가 같은지 검사한다. 배치 조정에서는 변경된 목차·페이지 참조·링크·책갈피를 검사한다.
3. 보호 문구를 원문과 문자 단위로 비교한다. 문자열 존재만으로 검증을 끝내지 말고 출현 횟수, 문맥과 코드·로그의 줄바꿈도 확인한다. 이미지 내부 원문은 시각 비교한다.
4. 모든 페이지를 PNG로 렌더링하고 전체 접촉표와 글자가 많은 페이지를 원본 크기로 확인한다.
5. 겹침, 잘림, 누락, 네모 글자, 불필요한 빈 페이지, 잘못된 줄바꿈을 수정한다. 원형 유지에서는 이미지·표 이동을, 배치 조정에서는 그림·표와 설명의 분리를 검사한다.
6. 번역 대상 영어 설명이 남았는지 검색한다. 고유명사와 보호 문구는 제외한다.

검증 전에는 완료라고 보고하지 않는다. 결과 PDF를 전달하며 적용한 배치 방식, 원본 보존 여부와 보호 범위를 짧게 보고한다. 중간 분석·렌더링 파일은 사용자가 요청한 경우에만 산출물로 전달한다.
