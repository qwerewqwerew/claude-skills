# 배치 보존과 품질 검사

## 원형 유지

페이지 수·크기와 이미지·도형·표·배경의 위치·크기를 유지한다. 제목·본문·캡션의 위계와 텍스트 정렬을 보존한다. 번역문은 원문 영역 안에 배치하고 줄바꿈과 자간·행간을 먼저 조정한다. 읽기 어려운 축소나 내용 요약으로 맞추지 않는다.

출력 페이지 수와 대응 페이지의 너비·높이·회전·표시 영역을 비교한다. 크기 차이에 허용 오차를 적용한다면 측정 정밀도에 맞게 설정하고 기록한다. 텍스트 추출만으로 배치 보존을 확정하지 않는다.

## 한국어 배치 조정

원문의 의미와 내용의 완전성, 보호 문구의 정확한 표기를 우선한다. 읽기 순서와 제목 위계, 이미지·표와 설명의 연결을 유지한다. 텍스트 영역·표 셀·이미지 위치와 페이지 나눔을 조정할 수 있다. 정상적인 이동·페이지 추가를 오류로 취급하지 않는다.

원문 각 내용 블록이 결과와 누락·중복 없이 대응하는지 검사한다. 페이지 변경 후 목차·본문 페이지 참조·링크·책갈피를 갱신하고 도착 위치를 확인한다.

## 원문 제거와 보호

- 단색 배경은 원래 배경색으로 글자 영역만 복원한다.
- 복잡한 배경은 원본 편집 객체나 주변 픽셀 복원을 검토한다. 큰 손상이 예상되면 방향을 묻는다.
- 표 테두리·배경·이미지·선을 함께 제거하지 않는다. 글자 제거 작업의 영향을 확인한다.
- 흰 사각형으로 덮기만 하면 원문이 추출되거나 검색될 수 있다. 교체 대상 원문이 실제로 제거됐는지도 확인한다.
- 보호 문구의 추출 순서가 달라지면 블록·좌표와 시각 비교를 보완한다. 코드·로그의 공백과 줄바꿈을 임의로 정규화하여 통과시키지 않는다.

## 시각 검사

모든 페이지를 렌더링하고 접촉표에서 빈 페이지, 사라진 도판, 페이지 밖 글자를 찾는다. 글자가 많은 페이지, 표·여러 열, 작은 각주·캡션, 배경 위 글자, 축소한 글자는 원본 크기로 확대한다. 한글 글꼴 누락, 잘림, 겹침, 잘못된 줄바꿈을 수정한다.

출력 파일을 열 수 없거나 필요한 글꼴·OCR·렌더링 도구를 확보하지 못한 경우, 보호 범위를 구분하지 못한 경우에는 검증 완료로 처리하지 않는다. 확인한 사실과 영향받는 부분, 가능한 대안을 짧게 보고한다.
